# 李白 × 杜甫：诗歌回响

一个直接读取工作区三份 CSV 的交互式数字人文网页。无需安装 npm 包或构建前端项目。

## 运行

在 Windows 上双击 `start.bat`，浏览器会打开 `http://localhost:8000`，并在当前目录启动 Python 静态文件服务器。也可以在项目目录运行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。请通过本地 HTTP 服务打开页面，不要直接双击 `index.html`，因为浏览器会阻止 `file://` 页面读取 CSV。

## 页面内容

- **序章**：从实际关联记录中动态选取一组李白、杜甫诗句。
- **语料**：展示原始关联记录数、按作品 ID 去重的作品组合数、诗句序号组合数、作品覆盖率、诗人语料作品数及关联度分布。
- **关系网络**：基于原始关联数据按作品或诗句展开局部网络；支持作品名搜索、按诗人聚焦当前关联量最高的 12 首作品、关联条数筛选、拖动节点、平移缩放、查看作品关系和诗句对照。下方热力矩阵随筛选联动，比较当前关联度最高的作品。
- **诗句回声**：按诗名双向检索关联作品，查看原诗全文和对应行，或随机打开一组真实关联。

## 数据处理

页面使用浏览器原生 CSV 解析器读取 `李杜/李白.csv`、`李杜/杜甫.csv` 和 `李杜/李白-杜甫.csv`，自动识别 UTF-8 与 GBK；未把第一条数据当作表头。两份诗歌语料按第四列诗歌 ID 和诗句序号还原作品与上下文；关联表按 H、J 列作品 ID 建立作品关系，并保留每条原始记录中的诗句、序号及 G 列分值。

重复关联记录不会在加载时丢弃。作品组合按双方作品 ID 聚合，页面会分别标示原始记录数、作品组合数及诗句序号组合数。G 列沿用源文件原始数值；页面不推断其语义或量纲，也不推断诗人的创作时间、人物交往或文学解释。无效或无法对应到作品的记录会从统计中排除并显示数量。

网页使用原生 HTML、CSS、JavaScript 与 SVG；无需外部图表库。中文字体可从系统字体回退；若可联网，标题字体会使用 Google Fonts。
